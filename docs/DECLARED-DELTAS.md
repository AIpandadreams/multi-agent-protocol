# Declared release deltas — `commands/wake.md` and `commands/sleep.md`

This register records, by date, the places where the published `/wake` and `/sleep` text DELIBERATELY differs from the
canonical deployment it was cut from. A row here means the difference is intended and will not be "fixed" by
a later reconciliation; a difference NOT recorded here is drift and is reconciled toward the canonical text.
Scope: that rule binds the text this release has PORTED from the canonical deployment. A published-vs-canonical
difference in text outside those ported ranges — including a path or reference that exists in only one of the two
trees — is outside this register and is not drift.
Rows are appended, never edited; a delta that stops being deliberate gets a new row saying so.
